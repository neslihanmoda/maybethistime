# AFTERIMAGE — maybethistime

This repository is a static front-end prototype for AFTERIMAGE, an independent digital magazine.

How to run locally:
- Clone the repo
- Open index.html in a browser (or use a small static server like `npx serve`)

What’s included:
- index.html, style.css, data.js, app.js
- Hash-based client-side routing
- Search overlay, newsletter demo, article pages, category pages, image archive

Notes:
- Newsletter form is a front-end demo and does not store email addresses.
- To publish with GitHub Pages, set the repository Pages source to `main` / `/root` and add your custom domain to Settings > Pages.
- DNS for apex domain: add A records for GitHub Pages (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) and CNAME for www to `nesrindemjr-hub.github.io`.
